My Learning Journey

Course: 21CSE354T — Full Stack Web Development · Unit 1

Chapter 1 — HTML: Structure of the Web
Structuring an HTML Document +

HTML documents follow a strict hierarchy: DOCTYPE declaration, <html>, <head> and <body>. Semantic elements like <header>, <main>, <section>, <article> and <footer> communicate meaning to both browsers and screen readers, improving accessibility and SEO.

Validating and Debugging Your Code +

The W3C Markup Validation Service checks HTML for syntax errors. Browser DevTools (F12) allow inspection of elements, computed styles and console logs — essential habits for catching bugs early and writing standards-compliant markup.

Working with Fonts and Text Blocks +

HTML provides rich text-formatting tags: <h1>–<h6> for headings, <p>, <strong>, <em>, <small>, <mark>, <blockquote>, <code>, <sub>, <sup> and more. Web fonts are loaded via CSS @import (e.g., Google Fonts) for consistent cross-platform typography.

Lists and Tables +

Ordered (<ol>) and unordered (<ul>) lists structure sequential and grouped content; <dl> handles definition pairs. Tables (<table>, <thead>, <tbody>, <th>, <td>) represent tabular data, with colspan and rowspan merging cells — as demonstrated in the Certifications table on the About page.

Using External and Internal Links +

The <a> element creates hyperlinks. Internal links navigate between pages or anchor points (href="#id"). External links point to other sites (target="_blank" rel="noopener"). Mailto links (href="mailto:...") open an email client. Anchor IDs enable in-page navigation like a Back-to-top button.

Working with Colors, Images and Multimedia +

Images (<img>) must carry descriptive alt attributes for accessibility; object-fit controls how they fill their container. HTML5 <video> and <audio> with controls attribute bring native media playback. Colors are applied via CSS using hex, rgb, hsl or custom property (variable) values.

Chapter 2 — CSS: Visual Design of the Web
Understanding Cascading Style Sheets +

CSS rules have three parts: selector, property, value. The cascade determines which rule wins when multiple rules target the same element, based on specificity, source order and !important. Inheritance lets child elements receive certain style values from their parents automatically.

Working with Margins, Padding, Alignment and Floating +

Margin creates space outside an element; padding creates space inside. float: left/right takes an element out of normal flow so text wraps around it — used for the profile photo on the About page. The clearfix pattern (:after { clear: both }) prevents container collapse after floated children.

Understanding the CSS Box Model and Positioning +

Every element is a box made of content, padding, border and margin. box-sizing: border-box includes padding and border in the stated width. The position property (static, relative, absolute, fixed, sticky) controls element placement; absolute elements are positioned relative to the nearest non-static ancestor.

Using CSS for Lists, Text and Navigation +

list-style controls bullet type or removes them. text-align, font-weight, letter-spacing, text-transform and line-height shape typography. Navigation bars are built by styling <nav> > <ul> with display:flex or display:inline-block, removing list-style and adding hover transitions.

Creating Layouts Using Modern CSS Techniques +

Flexbox (display:flex) aligns items on one axis — ideal for navigation bars, button rows and hero layouts. CSS Grid (display:grid) arranges content on two axes, enabling responsive card grids with grid-template-columns and minmax(). Both are used throughout this portfolio.

Taking Control of Backgrounds and Borders +

background-color, background-image, linear-gradient() and radial-gradient() paint element backgrounds. border-style accepts solid, dashed, dotted, double and groove. border-radius rounds corners, and box-shadow adds depth with optional color glow effects — demonstrated in the Border Styles Demo above.

Using CSS Transformations and Transitions +

transform applies 2D/3D effects: translateX/Y (move), scale (resize), rotate (spin), skew. transition smooths property changes over time (duration + easing). The project cards on this site use translateY + scale on hover; the CSS Hover Demo on the Projects page shows all three transforms live.

Animating with CSS +

@keyframes defines named animation sequences with percentage waypoints. animation shorthand sets name, duration, easing, delay and iteration-count. This site uses fade-in-up (hero text entrance), float (profile photo), spin-ring (conic-gradient ring), bar-grow (progress bars) and bounce-scroll (scroll hint).

Canvas +

The HTML5 <canvas> element provides a pixel-based drawing surface accessed via the 2D rendering context (getContext('2d')). JavaScript methods like fillRect, beginPath, arc, createLinearGradient and requestAnimationFrame create smooth animated graphics — powering the Learning Progress Chart below.
